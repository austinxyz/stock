# TQQQ 买入信号算法设计文档

**日期**：2026-03-27
**目标**：为 TQQQ 长线加仓决策提供辅助信号，支持历史回测验证策略有效性。

---

## 背景

用户当前持有 TQQQ 约 $5,000，浮亏约 20%。计划追加最多 $10,000。本算法通过综合多维技术指标生成 0–100 的信号分，信号分决定是否买入以及建议投入金额。

---

## 一、整体架构

```
数据层
  Alpha Vantage API → QQQ + TQQQ 日线 OHLCV（TIME_SERIES_DAILY_ADJUSTED）

新增模块（集成至现有 Spring Boot + Vue 3 系统）
  ┌─────────────────────────────────────┐
  │       TQQQ Signal Engine            │
  │                                     │
  │  1. 指标计算层                        │
  │     - QQQ 60日高点回撤幅度            │
  │     - TQQQ RSI(14)                  │
  │     - TQQQ MACD(12,26,9)            │
  │     - TQQQ 布林带(20,2)              │
  │     - TQQQ ATR(14)                  │
  │                                     │
  │  2. 评分引擎                          │
  │     - 各指标打分 → 加权合并 → 总分 0-100│
  │                                     │
  │  3. 资金建议层                        │
  │     - 总分 → 建议投入金额（基于剩余预算）  │
  │                                     │
  │  4. 软止损监控                        │
  │     - 浮亏预警 + 宏观趋势预警           │
  │     - 红色预警期间屏蔽买入信号           │
  │                                     │
  │  5. 回测引擎                          │
  │     - 历史数据回放，输出收益/回撤/胜率    │
  └─────────────────────────────────────┘

前端
  TQQQ Dashboard 页面：实时信号分 + 买入建议 + 持仓状态 + 回测结果
```

模块独立，不影响现有代码，通过新 API 端点和前端页面暴露功能。

---

## 二、数据源

- **API**：Alpha Vantage `TIME_SERIES_DAILY_ADJUSTED`
- **标的**：QQQ（用于回撤和宏观判断）、TQQQ（用于技术指标）
- **频率**：每个交易日收盘后更新一次
- **免费 tier 限制**：5 次/分钟，25 次/天——两个标的每日各拉一次，完全满足
- **历史数据**：回测拉取近 5 年（约 1250 个交易日），覆盖 2020、2022、2024–2026 多个下跌周期

---

## 三、评分模型

总分 0–100，由五个维度加权合并。**触发门槛：总分 ≥ 40 才生成买入信号。**

### 3.1 各维度评分规则

| 维度 | 基于 | 权重 | 评分逻辑 |
|------|------|------|---------|
| 回撤幅度 | QQQ 近60日高点 vs 今日收盘 | 25分 | 回撤 < -10%=5分，-10%~-20%=15分，> -20%=25分 |
| RSI 超卖 | TQQQ RSI(14) | 25分 | RSI > 50=0分，40–50=5分，30–40=15分，< 30=25分 |
| MACD 状态 | TQQQ MACD(12,26,9) | 20分 | 柱由负转正=20分，负值区间底部收窄=10分，其他=0分 |
| 布林带位置 | TQQQ 收盘 vs 下轨 | 15分 | 跌破下轨=15分，在下轨5%以内=8分，其他=0分 |
| ATR 信号 | TQQQ ATR(14) vs 60日均值 | 15分 | ATR 曾超过60日均值1.5倍后开始回落=15分，ATR 在均值1.5倍以内=5分，ATR 仍高于均值1.5倍且未回落=0分 |

### 3.2 信号强度与资金建议

```
总分 < 40   → 不操作
总分 40–59  → 建议投入 remaining_budget × 15%
总分 60–79  → 建议投入 remaining_budget × 35%
总分 80–100 → 建议投入 remaining_budget × 50%
```

`remaining_budget` = 用户设定总预算 − 已累计买入金额（防止超投）。

## 四、软止损监控

软止损不自动执行，仅触发预警并附带建议供用户决策。

### 4.1 预警规则

| 触发条件 | 预警级别 | 系统建议 |
|---------|---------|---------|
| TQQQ 持仓浮亏 > 25% | 黄色 | 暂停新买入，等待反弹信号 |
| TQQQ 持仓浮亏 > 40% | 橙色 | 考虑减仓 50%，保留子弹等更低点 |
| QQQ 跌破 MA200 且持续 10 个交易日 | 红色 | 趋势可能转熊，评估是否全部离场 |
| QQQ 月线连续 3 根阴线 | 红色 | 宏观趋势恶化，暂停所有买入 |

### 4.2 关键规则
- 浮亏基于用户**平均成本**（所有买入的加权均价），不是单次买入价
- **红色预警期间，即使评分 ≥ 40 也屏蔽买入建议**
- 红色预警解除条件：QQQ 重新站上 MA200 并连续收于其上 5 个交易日

### 4.3 持仓追踪
系统记录每次手动买入（日期、数量、价格），实时计算：
- 加权平均成本
- 当前浮盈/浮亏 %
- 已用预算 / 剩余预算

## 五、回测引擎

### 5.1 回测参数
- **历史范围**：近 5 年 QQQ + TQQQ 日线数据
- **初始资金**：可配置（默认 $10,000）
- **初始仓位**：可设置（模拟当前已持仓状态）

### 5.2 回测流程
```
设置初始参数（资金、仓位）
↓
逐日回放历史价格数据
↓
每日计算评分 → 触发买入信号 → 模拟买入（扣减预算）
↓
止损预警触发 → 模拟减仓/暂停逻辑
↓
回测结束 → 输出结果指标
```

### 5.3 输出指标

| 指标 | 说明 |
|------|------|
| 总收益率 | 最终持仓市值 vs 总投入 |
| 最大回撤 | 持仓期间最大峰谷跌幅 |
| 信号触发次数 | 买入信号共触发几次 |
| 平均持有成本 | 所有买入的加权均价 |
| vs 一次性买入 | 对比在回测起点全仓买入的结果 |

### 5.4 参数调优
回测界面支持调整各指标权重和触发门槛，对比不同参数组合的历史表现，找到最优权重配置。

## 六、前端 Dashboard

新增 TQQQ 专属页面，包含：
- **实时信号面板**：今日总分、各维度得分明细、买入建议金额
- **持仓状态**：平均成本、当前浮亏%、已用/剩余预算、止损预警状态
- **历史信号记录**：过去每次信号触发日期和分数
- **回测结果**：可配置参数，展示收益曲线、回撤图、与一次性买入的对比

---

## 七、集成方式

- **后端**：新增 `TqqqSignalService`、`TqqqBacktestService`、`TqqqPositionService`，对应新 REST 端点
- **数据库**：新增 `tqqq_signals`（信号历史）、`tqqq_positions`（手动持仓记录）两张表
- **Alpha Vantage**：复用或新增 `AlphaVantageClient`，与现有数据拉取机制并行
- **前端**：新增 `/tqqq` 路由和页面组件，不修改现有页面

---

## 八、不在范围内

- 自动下单执行（仅辅助决策）
- 多标的扩展（本期只做 TQQQ/QQQ）
- 期权策略
- 实时 tick 数据（日线已足够长线策略）
