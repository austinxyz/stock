## 评分系统（总分 100）

### 技术评分（50分，每日更新）

| 指标 | 满分 | 评分规则 |
|------|------|---------|
| 52周高点回撤 | 15 | ≤-50%: 15分 / ≤-30%: 10分 / ≤-15%: 5分 / >-15%: 0分 |
| RSI(14) | 15 | ≤25: 15分 / ≤35: 10分 / ≤45: 5分 / >45: 0分 |
| MACD 柱 | 10 | 金叉（负转正）: 10分 / 底部收窄: 5分 / 无信号: 0分 |
| 布林带 z-score | 10 | z<-2.0: 10分 / z<-1.5: 5分 / z≥-1.5: 0分 |

### 基本面评分（50分，`--full` 时更新，否则读缓存）

| 指标 | 满分 | 评分规则 | 数据来源 |
|------|------|---------|---------|
| 现金跑道 | 20 | >24个月: 20分 / >12个月: 13分 / >6个月: 6分 / ≤6个月: 0分（硬止损）| yfinance |
| 分析师目标价 | 15 | 目标价 >现价200%: 15分 / >150%: 10分 / >110%: 5分 / ≤110%: 0分 | yfinance |
| 营收/合同管道 | 10 | 近30天有新合同/LOI/MOU: 10分 / 近90天有: 5分 / 无: 0分 | SEC EDGAR 8-K |
| 论点完整性 | 5 | 无重大负面事件: 5分 / 有监管受阻或合同取消: 0分 | SEC EDGAR 8-K |

## 策略建议

### 止损触发（任一条件满足）
- 现价跌破止损线 **$34.61**（成本×30%）
- 现金跑道 < 6个月（基本面硬止损）
- 论点核心破坏（NRC 拒绝关键许可 / 主要合同批量取消）

### 加仓触发（所有条件同时满足）
- 技术评分 ≥ 35（技术面出现超卖信号）
- 现金跑道 > 12个月
- 无止损触发条件
- 现价高于止损线 $34.61

加仓建议金额：参照技术评分比例
- 技术分 ≥ 45：加仓预算的 40%（$2,000）
- 技术分 ≥ 35：加仓预算的 20%（$1,000）

### 持有
- 不满足止损条件，也不满足加仓条件

### 输出形式
三栏并列展示（止损 / 持有 / 加仓），当前命中的状态高亮，并列出具体触发/未触发的理由。

---

## HTML 报告结构

1. **持仓摘要卡片** — 现价、持仓市值、浮亏%、成本线、止损线、距止损线距离
2. **综合评分** — 总分/100，技术分/50 + 基本面分/50 分拆显示
3. **技术指标详情** — 每个指标一张卡片（当前值 + 评分规则 + 为什么）
4. **基本面详情** — 现金跑道、分析师目标价、近期 SEC 8-K 公告列表（显示上次更新时间）
5. **策略建议三栏** — 止损 / 持有 / 加仓，命中状态高亮，理由列表
6. **历史走势图** — 技术分 + 综合分双线
7. **历史记录表** — 所有历史日期的评分明细

## 技术实现

- **数据获取：** `yfinance`（价格 + 技术指标 + 基本面财务数据）
- **SEC 数据：** SEC EDGAR REST API（免费），拉取最近 10 条 8-K 标题
- **基本面缓存：** `oklo_fundamental.json`，记录上次更新时间；每日模式下直接读缓存
- **现金跑道计算：** `totalCash / abs(operatingCashflow)` × 12 个月
- **依赖：** `yfinance`, `pandas`, `numpy`, `requests`（SEC API）
